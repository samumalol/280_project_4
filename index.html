GEOMETRY

A.2 - Recovering the homography

H maps a source point (x, y) into the reference image (u, v). The final homogeneous coordinate must be divided out.

H = [[a, b, c], [d, e, f], [g, h, 1]]

u = (ax + by + c) / (gx + hy + 1)

v = (dx + ey + f) / (gx + hy + 1)



[x y 1 0 0 0 -ux -uy] q = u

[0 0 0 x y 1 -vx -vy] q = v

q = [a b c d e f g h]^T

N pairs produce a 2N x 8 system A q = rhs. All selected pairs are used. Coordinates are centered and scaled to a mean distance of sqrt(2) before constructing the system. This reduces the scale imbalance between pixel coordinates and their products.

A = U diag(S) V^T

q = V ((U^T rhs) / S)

H = inverse(T_destination) H_normalized T_source

This is an overdetermined algebraic least-squares fit implemented with NumPy SVD, not a geometric reprojection-error optimizer. The smallest singular value is checked to reject degenerate configurations. The final matrix is scaled so H[2,2] = 1 when possible.

Correspondence provenance and diagnostics

The original 16 desk correspondences are preserved. Lecture-hall sets use visually selected architectural landmarks with local patch refinement. For set2 and set3, SIFT descriptor proposals were filtered by a mutual ratio test and custom NumPy RANSAC, then a spatially distributed subset was saved. The notebook fits its own H to these fixed pairs; OpenCV is not needed to reproduce it. These assisted correspondences are not claimed to be student-clicked points or a complete Part B implementation.

Reprojection error is measured in destination pixels on the fitted points; it is a diagnostic, not independent test accuracy. The right view contains appreciable foreground/background disagreement, so a single H cannot align every depth perfectly.

RESAMPLING

A.3 - Inverse warping

Forward-transforming pixels can leave gaps. Instead, each destination pixel asks where its color comes from in the source:

[x_h, y_h, w]^T = inverse(H) [u, v, 1]^T

x = x_h / w; y = y_h / w

The four source corners determine the full output bounds. Negative coordinates are retained with an explicit canvas origin. All mosaic images share the same bounds. A warp whose projective horizon crosses the source is rejected because its full projected extent is unbounded.

Nearest neighbor

Round the source coordinate to the nearest pixel center. This uses one color sample, is fast, and preserves hard pixel transitions, but diagonal edges can become jagged.

Bilinear

Let x0=floor(x), y0=floor(y), dx=x-x0, dy=y-y0. Combine the four neighboring samples:

I(x,y) = (1-dx)(1-dy) I[y0, x0]

       + dx(1-dy) I[y0, x1]

       + (1-dx)dy I[y1, x0]

       + dx dy I[y1, x1]

Bilinear sampling costs more arithmetic and smooths pixel transitions. It cannot recover lost detail and is not an anti-aliasing filter for strong minification. At the last row/column, neighbors are clamped. Out-of-image samples remain invalid rather than being confused with valid black pixels.

Rectification setup

Four corners of a presumed planar rectangle are mapped to an axis-aligned output rectangle. Their order is top-left, top-right, bottom-right, bottom-left. The chosen output aspect ratios are display assumptions, not measured physical dimensions. Rectified outputs intentionally crop to the selected rectangle.

A.5 - CYLINDRICAL PROJECTION

A different projection surface

The left image pair is also projected onto a cylinder, using a chosen focal length f=1100 processing pixels and the reference image center. This is an uncalibrated visual choice.

s = f atan((u-cx)/f)

t = f (v-cy) / sqrt((u-cx)^2 + f^2)



Inverse:

u = cx + f tan(s/f)

v = cy + t / cos(s/f)

Each cylindrical output coordinate is converted into the reference camera plane, then through each inverse H into an original source image. Colors are sampled once from the original processing images and feathered. The planar panorama is not resampled a second time.

The cylindrical view reduces stretching toward the sides but changes the shape of horizontal lines and the image boundary. It does not correct errors in H, camera translation, or moving people, and is not a calibrated 360-degree panorama.

B.1

Detecting and selecting corners

The courtyard facade repeats similar window edges. Harris detects many points there. Adaptive non-maximal suppression (ANMS) spreads the feature budget across the image so overlaps away from the windows also contribute.

Gaussian derivatives at sigma 1 measure horizontal and vertical gradients. Their smoothed products form the 2 x 2 structure tensor (integration sigma 1.5). The response is its determinant divided by its trace. Peaks must be local maxima in a 5 x 5 neighborhood, exceed 0.0005 times the peak response, and have a 20-pixel descriptor margin. Up to 6,000 candidates enter ANMS.

For each candidate, the suppression radius is its distance to the nearest corner whose score exceeds its own score divided by 0.9. Candidates without such a neighbor have infinite radius. The 1,100 largest radii are retained when available.

Brown, Szeliski and Winder, Multi-Image Matching using Multi-Scale Oriented Patches (2005)

B.2

Describing each corner

Each 40 x 40 grayscale patch is divided into 64 cells. Averaging the 25 intensities in each cell both smooths and downsamples the patch. The resulting 8 x 8 array is centered by subtracting its mean and divided by its standard deviation. Nearly constant patches are discarded.

Each descriptor has 64 entries. Standardization helps match the same structure under additive brightness shifts and positive contrast changes. The bottom row uses a common display range from -2 to +2 standard deviations. Matching uses the unclipped values.

B.3

Finding corresponding patches

Each source descriptor is compared with all reference descriptors using Euclidean distance. A match passes when the closest distance is less than 0.82 times the second-closest distance and the source is also the nearest neighbor in the reverse direction. Similar-looking windows can still pass both checks. Each line connects a pair before geometric filtering.

B.4

Estimating geometry with four-point RANSAC

Each trial samples four distinct matches and estimates H with the normalized SVD solver from Part A. Degenerate samples are skipped. An inlier projects within 4 reference-image pixels of its matched point. Models are ranked by inlier count, breaking ties by median inlier error. The trial budget adapts to the best consensus fraction, with a floor of 100 trials and a cap of 6,000. The winning H is refitted on its inliers.

B.5

Multiscale detection and description

The extension detects corners and extracts descriptors at two Gaussian-pyramid levels. The second level smooths the image at sigma 1 and samples every second pixel in each direction. Its 40-pixel patches span approximately 80 pixels in the original image. Level coordinates are multiplied by two before geometry estimation. Descriptors from both levels are pooled for matching.

The controlled experiment matches the courtyard reference to a half-size copy. Both runs have a budget of 1,100 features per image. The two-level run splits the budget evenly. A correct match lands within 3 target pixels of the known position (x/2, y/2). The single-level run recovered 9 correct matches from 53 accepted pairs. The two-level run recovered 550 from 555, including 550 correct matches between different levels. This measures scale change on one photograph. The five photographic mosaics above use the single-scale pipeline.

Near objects and moving people can still appear doubled because a single H aligns only one projective motion. The black border shows the extent of the finite output canvas.

B.5

Rotation invariance

The B.2 descriptor samples an axis-aligned window, so rotating the photograph changes all 64 values. Following MOPS, each corner is given a dominant orientation. The image is blurred with a Gaussian of sigma 4.5, and the angle of its gradient at the corner, atan2(gy, gx), sets the patch axes. The 40 x 40 sampling grid is rotated by that angle and read with the bilinear interpolation from Part A. Averaging 5 x 5 cells and standardization are unchanged.

The controlled experiment matches the courtyard reference to a copy rotated by a known homography H. A correct match lands within 3 target pixels of H applied to the source point. A rotated window reaches 28.3 pixels from its center, so both images keep only corners more than 29 pixels from the image edge and from the black fill. At 30 degrees the axis-aligned descriptor recovered 3 correct matches from 28 accepted pairs. The oriented descriptor recovered 803 from 806.
